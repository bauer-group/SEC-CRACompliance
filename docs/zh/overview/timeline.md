# 1.3 时间表与截止日期

## 1.3.1 CRA 时间表

网络弹性法案（法规 (EU) 2024/2847）于2024年11月20日在《欧盟官方公报》上发布，并于2024年12月10日生效。

### 关键截止日期

| 日期 | 要求 | 状态 |
|------|-------------|--------|
| 10.12.2024 | CRA **生效** | 已完成 |
| 11.06.2026 | 通知机构及合格评定机构的程序开始适用（第四章） | 准备中 |
| **11.09.2026** | **报告义务生效** – Art. 14 CRA（被积极利用的漏洞、严重事件）；ENISA SRP 投入运行 | **需要行动** |
| 11.12.2026 | 已指定足够的通知机构（避免能力瓶颈） | 关注中 |
| 20.01.2027 | 机械法规 (EU) 2023/1230 全面适用 —— 与[既有证书](/zh/clarifications/sectoral-law-and-certificates)相关 | 关注中 |
| **11.12.2027** | **全面适用** – 所有要求，包括合格评定、CE 标志、技术文档 | **需要行动** |
| **11.06.2028** | **Art. 69(1) 的硬性终点**：依其他欧盟协调立法签发的 EU 型式检验证书与批准决定不再可用作 CRA 证据 | **需要行动** |

::: danger 自2026年9月11日起的报告义务
自2026年9月11日起，被积极利用的漏洞 (Actively Exploited Vulnerabilities) 必须在**24小时**内向 ENISA / 有管辖权的国家机构报告。事件响应流程必须在此日期前全面运行。

该义务涵盖 **CRA 范围内的所有产品——包括 2027.12.11 之前投放市场的产品**，并在产品支持期结束后**继续存在**。但对于制造商在 2026.09.11 之前即已知悉的主动利用，**无需追溯报告**。参见 [4.3 ENISA 报告流程](/zh/incident-response/enisa-reporting)。
:::

::: info 欧盟委员会指南 (Art. 26) —— 正式通过尚待完成
**2026 年 7 月 27 日**，委员会批准了其 CRA 适用指南的**内容**。正式通过将在所有欧盟语言版本齐备后进行，指南自该时点起才适用。其解释已被纳入本手册——来源、法律地位与完整对应关系见[欧盟委员会 CRA 指南](/zh/clarifications/commission-guidance)。
:::

### 详细时间表

**第一阶段：准备期（至2026年6月11日）**

- 创建产品目录并进行 CRA 分类
- 建立和验证 SBOM 流程
- 创建和测试事件响应手册
- 准备 ENISA 通知模板
- 实施 CVE 监控工作流

**第二阶段：报告义务期（自2026年9月11日起）**

- 报告流程必须可运行
- 使用 ENISA 统一报告平台 (SRP)
- 被积极利用漏洞／严重事件的24小时早期预警
- 72小时包含详细评估的通知
- 最终报告：漏洞为14天（自纠正措施可用起），严重事件为1个月（自72小时通知起）

**第三阶段：全面合规期（自2027年12月11日起）**

- 符合 Annex VII 的技术文档完整
- 每个产品的欧盟符合性声明（Annex V）
- CE 标志
- 已完成合格评定
- 已声明并公布支持期
- 每个发布的产品均有可用的 SBOM
- 已按照 Annex II 提供用户信息
